# ✨ About
- **ForeverTogether is a single-page website designed to feel like unwrapping a digital gift.
It opens with an animated reveal, leads into a personalized message, and includes small interactive touches — all built to create a genuine "surprise" moment for the person opening it.**
**This project was built as a personal gift, then open-sourced as a template others can adapt for their own friends.**

>; the code was generated with help from an AI assistant.

# 🚀 Features
- 🎁 Animated "gift reveal" landing screen
- 💌 Personalized, animated message section
- 📸 Optional memories/moments gallery
- 🎈 Interactive elements (confetti, floating hearts, etc.)
- 🎵 Background music — "Friends" by Marshmello & Anne-Marie
- 🌗 Dark / Light mode toggle (remembers your preference)
- 📱 Fully responsive — works on mobile and desktop
- ⚡ No backend, no dependencies to install — just open and go

# 🛠️ Tech Stack
- HTML5 — structure
- CSS3 — styling, theming, and animations
- JavaScript (Vanilla) — interactivity and animation logic
- Deployed with Surge (or any static host, e.g. GitHub Pages, Netlify, Vercel)
- **No frameworks, no build tools, no backend — just open index.html in a browser.**

# 💻 Running Locally
1. Clone the repo
```bash
git clone https://github.com/sahilcodes216/Forever-Together.git
```
2. Open the folder
```bash
cd ForeverTogether
```
3. Just open `index.html` in your browser — no build step or server needed. *(Optional: use the Live Server VS Code extension for auto-reload during editing.)*

# ☁️ Deployment
This project is deployed using Surge, a simple static site hosting CLI (Command-Line Interface).
- Live at: https://friendship-gift.surge.sh/

To deploy your own copy:
1. Install Surge (if you haven't already):
   
   ```bash
   npm install --global surge
   ```
2. From the project folder, run:

   ```bash
   surge
   ```
3. Follow the prompts to set your domain (e.g. `your-name.surge.sh`) and publish.
